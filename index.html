Lists in HTML

Use lists to group related information. Choose the list type that best describes the relationship between its items.

A practical reference · HTML5 · No JavaScript

01

NO SPECIFIC ORDER

Unordered list

Use <ul> when the order of the items does not matter. Each item belongs inside an <li> element.

Example

  • Notebook
  • Pen
  • Water bottle

Nested list

  • Plan the trip
    • Choose a destination
    • Check the weather
  • Pack a bag
02

A SEQUENCE OR RANKING

Ordered list

Use <ol> when sequence matters, such as instructions or ranked results. The browser numbers each <li> automatically.

Steps

  1. Gather your ingredients
  2. Mix until smooth
  3. Bake until golden

Other numbering styles

  1. Uppercase letters
  2. Second item
  1. Lowercase letters
  2. Second item
  1. Uppercase Roman
  2. Second item
  1. Lowercase Roman
  2. Second item

Useful ordered-list attributes

  • start="5"Start numbering from a specific value.
  • reversedCount items down instead of up.
  • type="A"Choose numbers, letters, or Roman numerals.
03

TERMS AND EXPLANATIONS

Description list

Use <dl> to pair terms in <dt> elements with their descriptions in <dd> elements.

Common HTML list elements

<ul>
Defines an unordered list of items.
<ol>
Defines an ordered list of items.
<li>
Defines an item in an ordered or unordered list.
<dl>
Groups a list of terms with their descriptions.
<dt> and <dd>
Define a term and its description inside a description list.
04

A QUICK RULE OF THUMB

Which list should I use?

  • Unordered listItems can appear in any order.
  • Ordered listItems follow a sequence or ranking.
  • Description listEach term has a related explanation or value.

Keep list markup semantic. Browsers and assistive technologies use it to communicate how content is grouped.
